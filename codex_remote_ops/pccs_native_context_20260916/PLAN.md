# PCCS 内部上下文一致性增强：方向修正

状态：设计记录，尚未实现或启动GPU实验。依据2026-09-16用户明确要求：保留PCCS主机制，将有用的context思路实现到现有基础模块内；既有外接O-MaMa实验保留为对照。

## 当前实现的真实归属

前几轮保留V2-SAM的Visual/Anchor/Fusion候选生成和原PCCS基线，之后使用公开O-MaMa的DINOv2、mask/context描述符、cross-attention、MLP及预训练权重重新匹配候选，可能覆盖原PCCS选择。因此它是“PCCS候选 + O-MaMa匹配/再排序”的组合基线，不能将借用的匹配核心写成自己的新context机制。后续小排序器/残差投影也未自动改变这一归属。

引用来源：[O-MaMa官方实现](https://github.com/Maria-SanVil/O-MaMa)，固定版本0f187c65cb9d8f8df1d8b5f445edbb0485956d88。借鉴“物体身份需要周边语义协助消歧”的动机必须引用；上下文本身、复用DINOv3、改模块名称或位置都不能单独证明创新性。

## 主方案：context辅助PCCS循环对应判别

PCCS现有主干保留：前向对应→SAM候选→反向对应→源mask循环检验→Fusion质量门及Visual/Anchor回退。新信息直接进入对应可信度与循环证据，目标是识别“外观相似且能形成假循环”的错误对象。

1. **复用现有DINOv3特征与对应。** 先给每个既有对应点增加context证据，不同时改变点数量、随机采样、SAM提示形式或Visual/Fusion特征池化。前向模块已有return_features接口；后向模块需要显式暴露对应位置、置信度及特征。各分支特征的预处理/网格必须分别核对，不能把不同网格直接混用。
2. **局部上下文支持与可靠性分开。** 源mask外的局部邻域作为context候选，目标使用预测mask外的邻域。用特征相似度、双向对应支持、匹配歧义和可用覆盖度判断邻域是否提供可信证据。先用邻域内无固定方向的匹配集合，不假设相机变化后邻居仍在相同左右位置；遮挡、视场不同、图像边界或小物体缺少有效patch时降低可靠性并回退。这里不需要检测或命名周围物体。
3. **在原循环检验内使用context。** 对“返回源mask的支持票”或对应置信度作有限幅度的上下文加权；可靠的context冲突才削弱某个对应的循环支持。保留原mask质量约束、循环成功判断及回退结构，避免用一个独立语义相似分数直接决定最终mask。不能把固定尺度整圈背景均值相似等同于可靠context。
4. **处理Fusion早退出。** 当前Exo→Ego/借权重Exo→Exo为fusion-first：面积/连通性合格就直接接收Fusion，否则才进入Visual/Anchor循环回退。仅改回退循环会绕过大部分已接收Fusion。独立消融“可靠context冲突时转入原PCCS循环复核”，不直接由context改选另一专家；缺少可靠证据时照常接受原输出。

形式上可将原循环证据P_i改成P_i + λ·r_i·Δ_context,i，其中r_i只反映context证据的可用性/可信度，Δ_context,i只校正现有对应或支持票。具体量纲和归一化在实现前与原PCCS的计数/距离规则对齐，不把原规则伪写成不存在的单一连续分数。λ=0或r=0必须从代码路径直接返回原实现，做到同seed下候选mask和最终路由逐位一致。

## 分阶段消融与贡献判断

首先保持候选mask不变，比较：原PCCS；仅context加权循环支持；仅Fusion可靠冲突复核；两项结合。外接O-MaMa作为单独组合基线。通过这一轮才能把新增效果归因到PCCS内部context机制。

其次仅在前一轮成立后，再将相同context可靠性用于前向候选点消歧，让SAM初始候选受益；单点数量先保持不变，独立比较候选Oracle、循环成功/错误接受率、最终IoU和计算开销。避免再次将“多点改变”和“context改变”混成同一个实验。

必须包含：关闭context精确复现原方法；context随机置换/错配或去除的干预对照；前景与周边信息分离；不可靠context回退；Fusion接收与回退子集的分层分析。所有路由只接收预测及源提示信息，目标GT仅用于评价。参数只用按take分离的训练/校准数据选择，固定后验证Exo→Exo；当前20个take已被反复观察，不能冒充新的盲测。

拟贡献应围绕“上下文支持的跨视角循环对应可靠性”，其有效性和区别于已有工作仍需文献对照及上述消融证明。已有O-MaMa组合增益没有单独证明context是增益来源；也不证明这套PCCS内部增强已经有效。本文档不产生新的实验数值。
