# O-MaMa 官方匹配头与固定 PCCS 候选探索

本轮使用作者公开的Exo→Ego预训练权重、DINOv2 ViT-B/14-reg、原版100像素整框描述提取和训练好的cross-attention+MLP。严格加载全部32个匹配头状态项，无缺失或额外键；规范尺寸下的候选分数及选择与原版forward一致。没有重新训练，没有用测试标签调参数。

## 与上一轮的区别

上一轮是冻结DINOv3上下文余弦覆写。本轮运行O-MaMa实际训练过的匹配网络，保留原PCCS、Visual、Anchor、Fusion的缓存mask，仅替换选择器。两轮的候选缓存完全相同，避免重新生成mask造成的随机采样差异。

本实验仍不是完整O-MaMa基准复现：候选来自V2-SAM而非FastSAM；每方向只有固定64对诊断样本，不能替代全量/独立验证。作者checkpoint的训练样本身份未独立审计。

## 测试时输入置零诊断

这一组保持同一官方checkpoint，只在推理时将context或cross-attention输出置零；它不等同于重新训练各结构的消融，置零本身也可能造成分布偏移。正常分支必须精确复现第一轮选择。

## 解释与后续边界

本轮在作者checkpoint原训练方向出现了明显的选择改善信号，简单object/context余弦没有同等改善；这支持进一步验证训练过的匹配头，而非继续将“扩大圈”视作充分改进。但迁移方向仍未获得一致增益，不能宣称通用提升，也不能把64对上的最高数字当作验证选出的配置。

测试时将context与cross-attention输出置零，没有降低当前Exo→Ego候选bank上的分数，反而略有提高。因此本轮正向信号不能归因于context本身；学习到的匹配表示和候选分布变化需要进一步区分。置零可能造成分布偏移，不能据此断言原论文模块无用。

若继续训练我们自己的头，应在训练集生成候选/正负样本，按take划分并在独立验证集选模型，再冻结设置评测测试集。当前原测试集及这些诊断样本不用于拟合参数。该后续训练尚未执行。
