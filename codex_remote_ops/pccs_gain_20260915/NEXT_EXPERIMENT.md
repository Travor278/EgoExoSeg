# 下一轮：学习何时替换 PCCS

512 对确认结果：PCCS 71.8812；完整 O-MaMa 加 0.05 门槛 72.9935，+1.1123 个点，但 95% 拍摄序列 bootstrap 区间为 [-0.8824, 2.7574]，尚未确认稳定收益。去除上下文和交叉注意力的预训练头为 71.5770，下降 0.3042 个点。

候选 oracle 的 frame IoU 上限比原 PCCS 高 6.1116 个点。直接 top-1 替换 555 个对象，其中 226 改善、287 变差；加门槛后替换 197 个对象，85 改善、79 变差。这支持研究替换判断，而不能证明任何新门控已经有效。

新实验位于 `gate_training`。从官方训练集按固定哈希选 48 个拍摄序列、384 对用于拟合，另 16 个序列、128 对用于选择模型和门槛。1,024 张所需图像从现有四个 TAR 归档按需提取，无需下载整个数据集。两部分序列不重叠，但原始专家看过官方训练集；这只是门控的训练内校准，分数不能当作测试收益。

输入是 65 项明确允许的预测信息：O-MaMa 完整/物体分数、SAM 置信度、mask 几何和候选一致性等。回归目标为候选相对 PCCS 的 IoU 增益。仅拟合岭回归和小型梯度提升树，V2-SAM、DINOv2 和 O-MaMa 主体均冻结。模型与门槛在校准部分选择；如没有正收益则保留原 PCCS。

已用 128 个真实候选检查特征：改写全部目标指标与 oracle 指标后，输入向量完全不变。候选只生成一次，缓存不覆盖。训练输入与监督标签分别存储。

未来测试队列提前冻结在 `gate_training/holdout_plan.json`：额外 64 个序列、512 对，排除之前所有 O-MaMa 探测和确认序列。只有在校准后冻结模型与门槛，才在新队列评价，不能根据新测试指标修改门槛。
